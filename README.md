# SIARB — Barber Lansmen | Evaluación de la APK

Repositorio público destinado **exclusivamente a distribuir la APK de evaluación y recibir comentarios** del proyecto académico SIARB — Barber Lansmen.

> **El código fuente no se publica aquí.** Este repositorio contiene instrucciones y materiales para la evaluación; la APK estará disponible cuando concluya su compilación y se publique una versión.

## Descargar la aplicación

**Estado: APK pendiente de publicación.**

Cuando la compilación esté lista, visita **[Releases (descargas)](https://github.com/Abelardo-117/siarb-evaluacion/releases)** y descarga el archivo `.apk` de la versión disponible.

### Instalación en Android

1. Descarga la APK desde una versión publicada en Releases.
2. Abre el archivo en tu dispositivo Android.
3. Si Android solicita permiso para instalar aplicaciones desde esa fuente, autorízalo solo si confías en el archivo descargado de este repositorio.
4. Abre **SIARB — Barber Lansmen**.

La aplicación está destinada a **Android**. No es un enlace de instalación para iPhone. Algunas funciones pueden requerir conexión a Internet y servicios externos.

## Qué puedes evaluar

- Diseño de la pantalla de acceso y registro.
- Navegación y claridad de los menús.
- Catálogo visual de servicios y barberos.
- Ubicación del establecimiento.
- Pantallas de perfil y experiencia general de uso.

**Alcance:** es una versión de evaluación académica. Algunas operaciones, en particular el flujo real de reservas, pueden no estar habilitadas o completadas. No se garantiza que todas las integraciones estén disponibles.

## Dejar tus comentarios

**[Abrir un comentario o reporte en GitHub Issues](https://github.com/Abelardo-117/siarb-evaluacion/issues/new/choose)** (requiere una cuenta de GitHub).

Cuéntanos:
- Qué pantalla o funcionalidad probaste.
- Qué funcionó bien y qué fue confuso.
- Qué error encontraste y cómo reproducirlo, si aplica.
- Qué cambiarías para mejorar la experiencia.

La rama **[`comentarios`](https://github.com/Abelardo-117/siarb-evaluacion/tree/comentarios)** conserva una guía para recopilar y organizar los resultados de la evaluación. **No necesitas editar esa rama:** usa Issues para enviar tu opinión.

**Privacidad:** no publiques contraseñas, tokens, correos privados, teléfonos, datos de clientes ni capturas que contengan información sensible. No compartas credenciales de administrador.

Recopilar observaciones constructivas de compañeros y docentes sobre la usabilidad, presentación y experiencia de SIARB — Barber Lansmen.
